# BALANCE — таблица баланса «Naruto RPG»

Сгенерировано `tools/balance.py` (симулятор `src/systems/sim.js`): 30 боёв на ячейку, бот-игрок с мастерством 0,4 / 0,65 / 0,85 (точность ритма, печатей и реакций). Характеристики героя берутся из модели роста «средний игрок» на день боя.

## 1. Формулы боя

| Что | Формула |
|---|---|
| HP героя | (60 + 4·Вын) × 1,1 с «Крепким орешком» |
| Чакра героя | 20 + 8·Чак (× 1,25 «Большой запас») |
| Шкала ходов | вес действия × fac(Скор), fac = max(0,6; 1,3 − 0,05·Скор) |
| Засада | Каварими: ×(1,4 + 0,04·Нин), Хенге: ×(1,8 + 0,04·Нин), куст ×1,5 |
| Блок врага против серии | 12% + 3%·(Тай врага − Тай) + 3%·(Скор врага − Скор) + 8% при Фокусе; 6–45%; урон ×0,5 |
| Финальное комбо (Воля) | 16 + 1,5·Тай, всегда крит |
| Уличные враги (хулиган, пёс, вор) | растут с днём: HP × (1 + 0,015·день), Тай +⌊день/14⌋, Скор и Вын +⌊день/21⌋ |
| Урон героя | база × (1 + 0,065·стат) / (1 + 0,04·Вын врага) × крит 1,5 / норма 1 / слабо 0,6 × комбо |
| Урон врага | база × (1 + 0,11·стат врага) / (1 + 0,03·Вын героя); блок ×0,55 (1 дыхание), уклон: 35% + 6%·(Скор − Скор врага) |
| Дыхание (тайдзюцу) | 2 + ⌊Вын / 3⌋ ячеек, +1 за ход без тайдзюцу, «Защита» +2 |
| Фокус (реакции) | 2 + «Аналитик» + флаг «Тактик» (из Академии) |
| Воля Огня | +урон получен ×0,8, +крит/уклон; 100 → «Воля Огня!» |
| Спарринг / свиток / колокольчик | победа при HP врага ≤30% (≤25% для колокольчика); поражение при своём ≤30% |

Приёмы тайдзюцу: Удар 5, Пинок 7, Подсечка 3, Апперкот 6.  
Комбо: Связка Академии ×1.15, Воздушное комбо ×1.28, Вихрь Листа ×1.38.  
Техники (цена чакры / печатей): Каварими 8/5, Хенге 8/3, Ложный страх 12/4, Буншин 14/3, Секси-дзюцу 6/1, Шуншин 15/1, Катон: Огненный шар 22/6, Суйтон: Водяная пуля 14/3, Райтон: Разряд 18/3, Футон: Порыв 15/3.

## 6. Выводы и что изменено по итогам симуляции

- **Было (первый прогон):** 95–100% побед во всех боях у всех сборок, даже у «новичка». Причины: урон героя не учитывал Выносливость врага; комбо перемножались (подсечка→апперкот ×1,5 × комбо ×1,6 × стат ×1,9 — «Воздушное комбо» снимало Ли 60% HP); 6 дыханий на старте = два комбо подряд; блок срезал 60% урона; финальное комбо Воли 28 + 2·Тай; модель роста (3+5 тренировок в день) выводила почти все статы на 12 к д.47.
- **Изменено:** урон героя ×(1 + 0,065·стат) / (1 + 0,04·Вын врага); комбо ×1,2 / 1,35 / 1,45; апперкот после подсечки ×1,3; приёмы 5/7/3/6; дыхание 2 + ⌊Вын/3⌋; блок ×0,55; враг может блокировать серию; урон врагов ×(1 + 0,11·стат); HP героя 60 + 4·Вын, «Крепкий орешек» ×1,1; финальное комбо 16 + 1,5·Тай; Воля с «Упорством» ×1,2; засады Каварими/Хенге растут с Нин; опыт до уровня 30 + 10·(стат − 3); HP сюжетных врагов +10–25%; уличные враги растут с днём; на полевом выходе — новый «Старшеклассник» вместо хулигана.
- **Ревизия после аудита:** в тренировочных боях (уроки, спарринги, турнир) расходники не тратятся; ловушки в бою требуют учебник «Теория ловушек»; встречный кунай — 3 + 0,35·Скор врага нажатий за 1,5 с (было 5 + 0,5·Скор за 1,3 с); оценка за урок-бой не ниже 50% при победе.
- **Сейчас:** «средний» игрок выигрывает обязательные бои примерно в 55–95%, новичок — заметно реже, опытный — почти всегда. Проигрыш в спаррингах и на турнире сюжет не ломает (есть ветки поражения).
- **Особенность сборок:** Тайдзюцу — самая «боевая»: её тренировки (манекен, бревно, крыши) качают ещё Скорость и Выносливость, а эксперимент показал, что именно они дают основной выигрыш (без +Вын: 88% → 61%, без +Скор: → 59%). Это осознанно: такой герой слабее в учёбе, на экзамене и в техниках. Ниндзюцу — самая трудная до Буншина (д.43): её урон идёт через засады Хенге/Каварими. Колокольчики Ируки почти не зависят от сборки (удача рывка).
- **Как перепроверить после правок:** `python3 tools/balance.py 40` — ячейки с ▲/▼ показывают выход «среднего» игрока из целевого окна.
