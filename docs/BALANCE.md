# BALANCE — таблица баланса «Naruto RPG»

Сгенерировано `tools/balance.py` → `tools/node/balance.js` (симулятор `src/systems/sim.js`, ядро боя `src/systems/duel.js`): 120 боёв на ячейку, зерно 20260518, бот-игрок с мастерством 0,4 / 0,65 / 0,85 (вероятность выбрать наилучшую карту, а не случайную). Характеристики героя берутся из модели роста «средний игрок» на день боя. Целевые окна — `tools/targets.json` (общие с проверкой `tools/node/checks.js`). Файл генерируется, руками его не правят.

## 1. Правила боя «Дуэль»

| Что | Формула |
|---|---|
| Ход | до трёх карт, затем противник выполняет точное намерение, видимое заранее; рука добирается до пяти, сброс перемешивается |
| HP героя | (60 + 5·Вын) × 1,1 с «Крепким орешком» |
| Чакра героя | 30 + 10·Чак (× 1,25 «Большой запас»); в начале хода после первого +6 + 0,5·Конт |
| Удар и серия | (5 + Тай) за Удар, три × (2 + 0,45·Тай) за Серию; +8% за звено тайдзюцу в этом ходу; ×0,85 при усталости >70 |
| Техники | своя формула у каждой карты; метка куная ×1,5, Фокус/Анализ ×1,25, Суйтон → Райтон ×1,6; мини-игр в бою нет |
| Урон врага | доля максимального здоровья героя: `hpMax × share` (см. §2); серия — два ×0,70 доли; приём — ×сила, но не больше 0,75 доли, и пробивает блок; заряженный приём ещё ×1,25 (всегда меньше полного здоровья) |
| Защита | Блок = зд. × (0,10 + 0,015·Вын) за «Защиту» и зд. × (0,06 + 0,010·Вын) за «Стойку», тратится по урону; контрудары Стойки и Каварими — тоже долей здоровья; Уклон = 65%; Каварими/Шуншин/дым = 100% и работают под связкой |
| Намерение | видно точно: тип, серия, ожидаемый урон после текущей защиты; замах срывают три звена тайдзюцу за ход |
| Усталость | +0,45 за карту и +0,5 за технику; +1,1 × (1 − 0,025·Вын) за ход; >70 урон ×0,85, >90 ×0,7 |
| Накал | +3 за обычную карту, +5 при ударе по герою, +2 за ход; от 60 доступен «Выброс» за 25 чакры |
| Фиолетовый срыв | шанс = (1 − стабильность) × затраты / 40, не больше 40%; усиление ×1,5 или отдача 25% урона |
| Спарринг / survive | спарринг — до 30% здоровья одного из бойцов; survive — N ходов; ko — до нуля |

Техники (цена чакры / печатей на тренировке): Каварими 8/5, Хенге 8/3, Ложный страх 12/4, Буншин 14/3, Секси-дзюцу 6/1, Шуншин 15/1, Выстрел чакры 10/2, Катон: Огненный шар 22/6, Суйтон: Водяная пуля 14/3, Райтон: Разряд 18/3, Футон: Порыв 15/3.
