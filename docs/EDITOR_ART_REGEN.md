# Графика объектов редактора

Актуально на 2026-10-21. **Все 36 новых мастеров подключены.** Это отдельный
набор редактора, не замена игрового окружения из [ART_STYLE.md](ART_STYLE.md).
История изменений — [CHANGELOG.md](CHANGELOG.md); управление — [MAP_EDITOR.md](MAP_EDITOR.md).

## Источник истины

| Файл/каталог от корня | Назначение |
|---|---|
| `art/editor-world/*.webp` | 36 независимых прозрачных мастеров, до 512px |
| `art/editor-world/manifest.json` | ID, имя файла, хэши мастера/исходника, статус `integrated-editor` |
| `tools/editor_art_specs.json` | Логические размеры и точки опоры, совместимые с прежними проектами |
| `tools/import_editor_art.py` | Подготовка компактных палитровых данных из WebP |
| `src/editor/generated_art_data.js` | Результат импорта; вручную не править |
| `src/editor/generated_art.js` | Синхронный декодер `G.editorArt` |
| `src/editor/village_art.js` | Совместимый интерфейс пяти укреплений |
| `tools/build_phone_editor.py` | Включает данные/декодер в автономный `map-editor.html` |

Исходные генерации `assets/src/editor-world/*.png` не входят в Git и не нужны
для обычной сборки. Хэши исходников — запись происхождения, а не требование
наличия PNG на машине. Для повторного импорта достаточно сохранённых WebP.
Презентационные JPG-листы удалены: они дублировали мастеры и не использовались.

## Пересборка

Обычная сборка не требует Pillow и не генерирует арт заново:

```bash
python3 build.py
```

После изменения мастеров или спецификации (нужен Pillow):

```bash
python3 tools/import_editor_art.py
python3 build.py
python3 tools/check_node.py
node tools/test_editor_art.js
```

Браузер, сервер и остальные проверки: [TESTING.md](TESTING.md).
При замене WebP обновите `master_sha256` в manifest. Импортёр сам manifest не обновляет.

## Контракты и ограничения

- Все рисунки с верхним ракурсом; не заменять фронтальными или изометрическими.
- ID, размеры рамок и точки опоры сохранены: JSON v1/v2 не требует миграции.
- Мастеры вписываются пропорционально с прозрачным полем. Горизонтальная стена —
  центральный фрагмент своего длинного мастера, без растягивания.
- Палитра, карта и PNG используют один декодер. Загрузка синхронная, без сети;
  автономный HTML работает через file://, в том числе при отключённой сети.
- Прямая стена: шаг 2 клетки. У ворот заход под крышу на 1 клетку:
  ворота x=12 → примыкающие стены x=11 и x=19, одинаковый y, масштаб 100%.
- Угол/продольные секции допускают наложение. Это не автотайлы: фактура стыков
  может оставаться заметной. Масштаб и отражения требуют визуальной проверки.
- Ворота — изображение, не игровая дверь. Рамки — не коллизии. Этот набор
  не меняет игровую Коноху, баланс или сохранения игры.

`test_editor_art.js` проверяет 36 ID и рамок, реальные пиксели PNG с отражениями,
JSON, восстановление и file://. Физические iPhone не тестировались — только эмуляция.
