# Naruto RPG: «Воля Огня. Путь в Академию»: план разработки (v2)

> Фанатская игра для личного пользования.
> **Симулятор жизни ученика академии ниндзя** с открытым миром: пиксельная RPG с видом сверху. Работает в мобильном браузере, весь код в **одном HTML-файле**, экран под **iPhone 15 Pro**.

---

## 0. Ключевые решения

| Параметр | Решение |
|---|---|
| Жанр | **Симулятор жизни ниндзя** и RPG: календарь, учёба, тренировки, подработки, дружба, сюжет |
| Мир | Свой герой в каноничной Конохе (время выпуска Наруто). Вся деревня, как в аниме |
| Перемещение | **Свободная ходьба** по одной бесшовной карте Конохи. Каждое здание — **отдельная локация-интерьер** |
| Бой | Пошаговая **дуэль 1 на 1** в стиле аниме: дистанция, шкала ходов, реакции (Каварими), обман, печати рук |
| Длительность | 8 игровых недель (56 дней) ≈ **6–10 часов** ✅ согласовано |
| Управление | **Сенсорное, без экранных кнопок**: плавающий джойстик под пальцем, кнопка действия появляется рядом, когда есть с чем взаимодействовать, «Назад» в окнах, значки «Меню / Карта / Цель» в нижней полосе; на ПК клавиатура. Вся площадь экрана отдана игре |
| Герой | **Парень**, 12 лет. Имя вводит игрок, внешность фиксирована. Предыстория: родители-шиноби погибли при нападении Девятихвостого, рос у родни на дальнем посту, вернулся в Коноху |
| Создание персонажа | Ввод **имени**, выбор **характеристик и стартовых навыков** |
| Имена | **Фанатская транслитерация**: Саске, Какаши, Шикамару, Чоджи, Теучи, Джирайя, Хенге, Буншин |
| Романтическая линия | Нет (только дружба и соперничество) |
| Сложность | Одна |
| Сохранение | **Один слот** в `localStorage`: автосейв во сне, при входе в здания и при сворачивании Safari, плюс скрытая резервная копия и экспорт кодом (см. 14) |
| Платформа | Safari на iPhone 15 Pro, портрет, запуск с иконки «Домой». Итог: `naruto_rpg.html` (вся игра) + крошечный `sw.js` (офлайн-кэш) |
| Эпилог | Герой становится **четвёртым членом** команды 7, 8 или 10: какой именно, зависит от дружбы |

## 1. Технические требования

### 1.1. Один HTML-файл (+ sw.js для офлайна)
- Внутри файла лежат HTML, CSS и JavaScript без внешних библиотек, CDN и картинок-файлов.
- Рядом лежит **`sw.js`** (~20 строк): Service Worker кэширует игру при первом запуске, потом она работает **полностью без интернета**. Обновление игры — просто заменить файлы на хостинге.
- Иконка для экрана «Домой» генерируется кодом (pixel-art протектор Листа).
- Графика генерируется кодом: пиксельные спрайты хранятся строками с палитрой.
- Звук синтезируется через Web Audio API (чиптюн).
- Ожидаемый размер файла ~0,6–1 МБ. Для Safari это нормально.

### 1.2. Как ведётся разработка
Игра большая, поэтому код удобнее держать **по модулям**, а одиночный HTML **собирать скриптом**:
```
/src
  engine/   (цикл, ввод, сцены, рендер)
  world/    (карта, генератор Конохи, интерьеры, NPC)
  battle/   (бой)
  life/     (время, нужды, тренировки, дружба, экономика)
  data/     (диалоги, NPC, техники, предметы, враги, сюжет)
  ui/       (HUD, меню, диалоги)
build.py    → склеивает всё в naruto_rpg.html (+ копирует sw.js)
```
Пользователь получает **один готовый файл**, а исходники остаются для правок.

### 1.3. Экран iPhone 15 Pro
- Логический экран **393 × 852 pt**: Dynamic Island сверху, полоска Home снизу.
- `viewport-fit=cover`, `env(safe-area-inset-*)`, `100dvh`, запрет зума и «резинки».
- Мета-теги `apple-mobile-web-app-capable`: через «На экран „Домой“» игра идёт на весь экран без панели Safari.

### 1.4. Раскладка экрана (на карте)
```
┌──────────────────────────┐  ← safe-area (Dynamic Island)
│ Пн, День 3 ☀ 14:20  120рё│  время, погода, деньги
│ ❤▮▮▮▮ 🌀▮▮▮ ⚡▮▮ 🍙▮▮     │  HP, чакра, энергия, сытость
├──────────────────────────┤
│                   ┌────┐ │
│      ИГРОВОЙ      │мини│ │  мини-карта в углу (вкл/выкл)
│      CANVAS       │карт│ │  внутр. разрешение 192×224
│  ◀ 120м 🍜        └────┘ │  ← стрелка к цели у края экрана
│        (масштаб ×2)      │  → 384×448 pt, pixelated
├──────────────────────────┤
│ 📜 Найти Ируку в Ичираку │  отслеживаемое задание
│    ⏰ с 18:00   [ЦЕЛЬ]   │  тап по [ЦЕЛЬ] показывает след к цели
├──────────────────────────┤
│    ▲                     │
│  ◀   ▶        (B)  (A)   │  D-pad + A (действие) / B (бег, прыжок)
│    ▼     [МЕНЮ] [КАРТА]  │
└──────────────────────────┘  ← safe-area (Home)
```
> **Адаптивная высота.** Свободного места: 852 − 59 (верх) − 34 (низ) ≈ 760 pt. В режиме «На экран „Домой“» всё помещается. В обычном Safari панели забирают ещё ~100 pt, поэтому высота canvas подстраивается (внутренняя высота 176–224 px), а геймпад не меньше 180 pt.

### 1.5. Особенности iOS Safari
- Мультитач: D-pad и B зажимаются одновременно (бег).
- Звук включается после первого касания (экран «Нажми, чтобы начать»).
- Ввод имени через скрытый `<input>`, открывается системная клавиатура.
- Вибрации нет, отдача передаётся тряской экрана и вспышками.

### 1.6. Запуск на телефоне
1. Загрузить `naruto_rpg.html` и `sw.js` в одну папку на **GitHub Pages** (или Netlify). Нужен HTTPS: без него Service Worker не работает.
2. Открыть ссылку в Safari (первый раз с интернетом) → «Поделиться» → **«На экран „Домой“»**.
3. Дальше игра запускается **только с иконки**, в том числе без интернета.
4. ⚠️ Сохранения в Safari и в иконке **разные**. Играть только через иконку. Для переноса есть экспорт и импорт кода в настройках.

Для разработки: `python -m http.server` на ПК и открыть по Wi-Fi.

## 2. Открытый мир: Коноха

### 2.1. Как устроена карта
- **Одна бесшовная карта** деревни ~**160 × 128 тайлов** (16 px). Пешком через всю деревню ~40 сек, по крышам быстрее.
- Отрисовка **чанками** 32×32 тайла в offscreen-canvas, рисуется только видимая область. Так держится 60 FPS.
- Карта **собирается генератором из данных**, а не рисуется вручную по тайлу:
  - районы — прямоугольники с типом застройки;
  - улицы — линии;
  - здания — шаблоны (дом, лавка, многоэтажка, особняк клана), которые ставятся по координатам;
  - уникальные объекты (Академия, резиденция Хокаге, Скала Хокаге, ворота) — отдельные шаблоны.
  Это компактно (килобайты) и легко правится.
- **Плавное движение** в 8 направлениях с коллизиями (не по клеткам).
- **Бег** (зажать B) тратит энергию.
- **Прыжки по крышам** открываются на неделе 5, после урока хождения по дереву (чакра в стопах). Запрыгнуть можно в **точках опоры** (бочка, забор, лестница, отмечены значком ⤒) кнопкой **A**. Так B (бег) у стены не вызывает случайных прыжков. С крыши на крышу прыжок автоматический при беге.
- **Слои:** земля → объекты → персонажи → крыши. Крыши становятся прозрачными, когда персонаж за зданием.
- **Освещение:** тонирование по времени суток, ночью светятся окна и фонари.
- **Погода:** ясно, облачно, дождь (частицы, лужи, людей на улице меньше).

### 2.4. Интерьеры (отдельные локации)
Вход через дверь (A) даёт переход с затемнением в отдельную карту.

**Уникальные:** дом героя, Академия (холл, 2 класса, кабинет Ируки, учительская), резиденция Хокаге (холл, кабинет), библиотека, больница, Ичираку, Якинику Q, оружейная, цветочная лавка, онсен, данго-лавка, особняки кланов (по 1 залу), дом Саске (заброшенный квартал), квартира Наруто.

**Шаблонные** (одна планировка с разной расстановкой): дома жителей, обычные лавки, склады. Около 25 уникальных и ~15 шаблонных интерьеров.

### 2.5. Жители
- **Именные персонажи** (~35) живут по **расписанию**: утром Ирука в академии, вечером в Ичираку; Шикамару днём смотрит на облака на крыше, Хината тренируется в квартале Хьюга.
- **Массовка** (~40) — генерируемые жители с простыми маршрутами, репликами и подработками.
- Ночью улицы пустеют, появляются другие люди и события.

### 2.6. Задания и навигация

#### Журнал заданий
- Задания делятся на категории:

  | Категория | Значок | Что это |
  |---|---|---|
  | **Сюжет** | 🔥 | Главные события недели |
  | **Академия** | 📘 | Уроки, домашние задания, экзамены |
  | **Поручения** | 📜 | Доска поручений, просьбы жителей, подработки |
  | **Дружба** | 🍃 | Сцены и просьбы друзей |
  | **Секреты** | ❓ | Спрятанные свитки, тайные события |

- У каждого задания есть описание, **шаги** (галочки), награда и, если нужно, **срок** («до пятницы») и **время** («только вечером»).
- **Отслеживается одно задание.** Оно показывается в строке цели под экраном, а направление к нему ведёт стрелка. Отслеживаемое задание переключается в журнале.
- Когда шаг выполнен, появляется всплывающее «✔ Шаг выполнен». Новое задание отмечается звуком и баннером «📜 Новое задание».

#### Направление к цели
1. **Строка цели под экраном:** текущий шаг («Найти Ируку в Ичираку») и условие по времени («⏰ с 18:00», «🌙 только ночью»). Если цель сейчас недоступна, строка серая и подсказывает, когда приходить.
2. **Стрелка у края экрана**, когда цель за пределами экрана:
   - указывает направление;
   - показывает расстояние (≈ 120 м);
   - показывает значок цели (🍜 Ичираку, 👤 персонаж, 📍 место).
3. **Метка над целью**, когда она на экране: прыгающий ▼ над местом или персонажем.
4. **Значки над NPC:**
   - **!** — у персонажа есть новое задание;
   - **?** — можно сдать задание;
   - **💬** — новая сцена дружбы.
5. **Умное направление через здания.** Направление учитывает здания и переходы:
   - цель внутри здания — стрелка ведёт **к двери**;
   - ты сам внутри — стрелка ведёт **к выходу**, затем дальше;
   - цель на втором этаже Академии — дверь, потом лестница, потом нужный класс.

   Это работает через **граф переходов** между локациями (двери, лестницы).
6. **Кнопка [ЦЕЛЬ] (след):** на несколько секунд на земле появляется **светящийся след** к цели (поиск пути A* по тайлам). Подаётся как «чутьё ниндзя».
7. **Своя метка:** игрок ставит свою точку на большой карте, например «Лавка с данго», и стрелка ведёт к ней, если ни одно задание не отслеживается.
8. Подсказки можно отключить в настройках, если хочется искать самому.

#### Мини-карта
- Квадрат в правом верхнем углу экрана, его можно включить или выключить.
- Показывает улицы и здания вокруг игрока, тебя (стрелкой по направлению взгляда), цель, значки **!** и **?**, двери магазинов.
- Внутри зданий показывает план помещения.
- Строится автоматически из тайловой карты: 1 пиксель на тайл.

#### Большая карта Конохи (кнопка КАРТА)
```
┌──────────────────────────┐
│  КАРТА КОНОХИ   Пн 14:20 │
├──────────────────────────┤
│ ▲▲▲ Скала Хокаге ▲▲▲     │
│  🏯      🏫 ▼      📚    │  ▼ — цель задания
│  🌲  ════════════  🏥    │
│      🍜 🛒 ⚔ 🌸         │  значки лавок (серые — закрыто)
│  ░░░  🏠◉     ░░░░░      │  ◉ — ты, ░ — неисследовано
│  🎯        ~~~~~~        │
│      ═══[ВОРОТА]═══      │
├──────────────────────────┤
│ 🍜 Ичираку рамен         │  карточка выбранного места
│ Открыто 11:00–23:00      │
│ Сейчас там: Наруто       │
│ [Проложить путь] [Метка] │
├──────────────────────────┤
│ Фильтр: Все|Задания|Лавки│
│ |Тренировки|Друзья       │
└──────────────────────────┘
```
- **Генерируется из той же карты мира**, поэтому всегда совпадает с игрой. 160×128 тайлов, масштаб ×2 → 320×256 pt, ширина экрана позволяет.
- **Управление:** D-pad или палец двигает курсор и карту, тап по месту открывает карточку, кнопка переключает масштаб (вся деревня или район).
- **Значки:** ты, цель задания, задания (!/?), лавки (серые, если закрыто), тренировочные места, дом, свои метки, найденные секреты.
- **Карточка места:** название, часы работы, **кто там сейчас** (по расписанию NPC), кнопки «Проложить путь» и «Поставить метку».
- **Фильтры:** Все, Задания, Лавки, Тренировки, Друзья.
- **«Где друзья?»:** при дружбе от 2 листков на карте видно, где сейчас находится этот персонаж.
- **Туман:** неисследованные районы закрыты, пока ты там не побывал. Купленная «Карта Конохи с секретами» добавляет подсказки, где искать свитки.
- **Быстрого перемещения нет**: это симуляция, по деревне ходишь сам. Ускоряют прыжки по крышам, а секретная техника **Шуншин** открывает мгновенное перемещение к дому, Академии и полигонам.

## 3. Создание персонажа

Начало игры — **пролог в больнице**, потом **вступительный тест академии** у Ируки.

### 3.0. Пролог: потеря памяти
- Героя нашли на рассвете у главных ворот (Идзумо и Котэцу): без сознания, без протектора и документов. Он ничего не помнит о себе.
- Новая игра → тёмный экран и голоса (сценарий `prologue_voices`) → палата больницы: рядом Третий Хокаге, Ирука и Сидзуне (`hosp_wake`).
- Хокаге просит назвать имя (ввод), узнаёт, что остальное герой не помнит, и решает: пусть станет шиноби — Ирука возьмёт его в выпускной класс
  Академии; жильё — «Дом героя» (первый вход: `home_first`). Дальше день 1 как раньше: Академия → Наруто → Ичираку → сон.
- Память не возвращается целиком: на 14-й день — обрывок видения (`st_memory`), в диалогах Ирука говорит «кем бы ты ни был раньше».

### 3.1. Имя
- В больнице Хокаге спрашивает «Как тебя зовут?» (`call askname`), игрок вводит имя (1–12 символов, кириллица или латиница). Имя подставляется во все диалоги через `{name}`.

### 3.2. Характеристики
База у всех по 3, игрок распределяет **12 очков**, максимум 7 на старте.

| Стат | Влияет на |
|---|---|
| **Тайдзюцу** | Урон рукопашного боя и метания, длина комбо |
| **Ниндзюцу** | Сила техник |
| **Гендзюцу** | Иллюзии, обман, сопротивление иллюзиям |
| **Чакра** | Максимум чакры |
| **Контроль чакры** | Время на печати, стоимость техник, хождение по деревьям и воде, прыжки по крышам |
| **Скорость** | Место на шкале ходов, уклонение, скорость бега |
| **Выносливость** | HP, энергия, выносливость в бою |
| **Знания** | Анализ врага, ловушки, письменные тесты, учёба в библиотеке |

### 3.3. Стартовые навыки (выбрать 2 из 9)

## 4. Бой «Дуэль шиноби»

**Цель:** чтобы бой **ощущался как в аниме** (скорость, обман, Каварими в последний момент, печати, крупные планы) и был **тактическим** (дистанция, порядок ходов, ресурсы, чтение врага).

### 4.1. Экран боя (вид сбоку)
```
┌──────────────────────────┐
│ ХОДЫ: [Я][Киба][Киба][Я][Киба][Я]  ← шкала ходов (таймлайн)
│ Киба  ❤▮▮▮▮▮ 🌀▮▮  намерение: ⚔→ │
├──────────────────────────┤
│    🌳          🌿            │  объекты местности
│  [1]  [2]  [3]  [4]  [5]     │  5 позиций — линия дистанции
│  {name}              Киба    │
├──────────────────────────┤
│ {name} ❤▮▮▮ 🌀▮▮▮ 💨▮▮  🔥ВОЛЯ ▮▮▯ │
│ Фокус: ◆◆◇                         │
├──────────────────────────┤
│ [ДВИЖЕНИЕ] [ТАЙДЗЮЦУ] [МЕТАНИЕ]   │
│ [НИНДЗЮЦУ] [ИНСТРУМЕНТ] [ЕЩЁ…]    │
└──────────────────────────┘
```

### 4.2. Ресурсы
| Ресурс | Назначение |
|---|---|
| **HP** | Здоровье |
| **Чакра** | Техники, Каварими, хождение по дереву и воде в бою |
| **Дыхание** 💨 | Тайдзюцу, рывки, уклонения. Восстанавливается защитой и паузами. Максимум зависит от стата Выносливость |
| **Фокус** ◆ | Очки реакций (2–3 за бой): Каварими, уклон, контратака |
| **Воля Огня** 🔥 | Шкала решимости для «кинематографичного момента» |
| **Подсумок** | Ограниченное число кунаев, сюрикенов и инструментов, взятых в бой |

### 4.3. Шкала ходов (тактика скорости)
- Сверху видна очередь из следующих 6 ходов.
- У каждого действия есть **вес**: быстрый удар или бросок куная лёгкие, техника на 5 печатей тяжёлая. Тяжёлое действие отодвигает твой следующий ход.
- **Скорость** сокращает вес действий.
- Некоторые действия **сбивают** врага на шкале назад: подсечка, оглушение, иллюзия.
- Отсюда выбор: несколько быстрых уколов или одна мощная техника, которая даст врагу два хода.

### 4.4. Дистанция и местность
- Поле — **линия из 5 позиций**. Расстояние между бойцами определяет, что можно делать:
  - **Вплотную** (соседние позиции): тайдзюцу, захваты.
  - **Средняя**: всё, кроме захватов.
  - **Дальняя**: метание, ниндзюцу. Тайдзюцу недоступно.
- **Местность** зависит от места боя:
  - 🌳 **Дерево**: залезть (нужен Контроль чакры) даёт укрытие от тайдзюцу и бонус к метанию сверху.
  - 🌿 **Кусты**: спрятаться, враг теряет тебя из виду, следующая атака будет засадой.
  - 💧 **Вода**: стоять можно только с хождением по воде, иначе это преграда.
  - 🪨 **Скала**: укрытие от метательного оружия.
  - 🪵 **Поленья**: Каварими с бонусом.
- Пример: Киба силён вплотную. Отскок к дереву, подъём наверх и сюрикены сверху — вполне тактика.

### 4.5. Действия
| Категория | Действия |
|---|---|
| **Движение** | Шаг, Рывок (2 позиции, 💨), Отскок (назад + уклон), Залезть / Спрыгнуть, Спрятаться |
| **Тайдзюцу** | **Цепочка из 1–3 приёмов**: Удар, Пинок, Подсечка, Апперкот, Захват. Удар по ритму (тап вовремя) даёт крит. Определённые цепочки складываются в **комбо**, например Подсечка → Апперкот → Удар в прыжке = «Воздушное комбо». Новым комбо учат Рок Ли и Гай |
| **Метание** | Кунай, сюрикен, веер из 3 сюрикенов (по Скорости), кунай с проволокой (притянуть, обездвижить) |
| **Ниндзюцу** | Выбор техники и **набор печатей** (см. 4.7) |
| **Инструменты** | Дымовая бомба (ослепление, шанс скрыться), световая бомба, **ловушки** на позицию: проволока, взрывная печать |
| **Ещё** | Защита, Концентрация (+чакра, уязвимость), **Анализ** (раскрыть слабость и намерения, зависит от Знаний), **Финт**, **Провокация**, Предмет, Сдаться (в спаррингах) |

### 4.6. Реакции: главное ощущение аниме
- Когда враг атакует, появляется окно **«РЕАКЦИЯ!»** примерно на 1,5 сек:
  - **Блок**: −💨, урон уменьшен.
  - **Уклон**: проверка Скорости.
  - **Каварими**: тратит ◆ Фокус и чакру, нужно быстро ввести 1 печать. Вместо тебя полено, ты оказываешься за спиной врага и получаешь бесплатную атаку.
  - **Встречный кунай**: вплотную, звон клинков и мини-дуэль на скорость тапов.
- **Враги тоже реагируют.** Умный противник уходит Каварими от твоей сильной атаки. Тогда сначала **Финтом** выманиваешь его реакцию, а потом бьёшь по-настоящему. Это аниме-«игра разумов».
- Фокус восстанавливается Концентрацией, Анализом и удачными комбо.

### 4.7. Печати рук
- Сетка из **12 печатей** с пиксельными иконками: Крыса, Бык, Тигр, Заяц, Дракон, Змея, Лошадь, Овца, Обезьяна, Птица, Собака, Кабан.
- Последовательность нужно набрать за время, которое зависит от Контроля чакры.
  - **Идеально**: техника усилена, бонус к Воле Огня.
  - **Нормально**: обычный эффект.
  - **Ошибка**: срыв, теряешь часть чакры, может появиться «пшик» дыма (комичный эффект как у Наруто).
- Когда **мастерство** техники растёт (уровни 1–3), подсказка последовательности исчезает, но печатей нужно меньше и они быстрее.
- Неизученные печати заблокированы и открываются по ходу учёбы.

### 4.8. Обман и иллюзии
- **Буншин**: на поле появляются 2 иллюзорных клона. Враг выбирает цель, и при промахе клон исчезает.
- **Хенге**: превратиться в объект местности (камень, полено, куст). Враг тебя теряет, засада наносит ×2 урона.
- **Гендзюцу**: враг видит **ложное намерение**, атакует пустое место или теряет ход.
- **Враги-обманщики** (Наруто с клонами, иллюзионисты): нужно найти настоящего по подсказкам (тень, следы, дыхание). Помогают Анализ и Гендзюцу.

### 4.9. Воля Огня: кинематографичный момент
- Шкала растёт от полученного урона, идеальных печатей, удачных реакций и разговоров в бою.
- Когда шкала полная, наступает **МОМЕНТ**: крупный план глаз героя, фраза, вспышка. Один ход с бонусом на выбор:
  - финальное комбо;
  - бесплатная техника на максимальной силе;
  - **второе дыхание**: половина HP.
- В сюжетных боях при низком HP бывают **флешбэки и диалоги** («Я не сдамся! Я стану генином!»).

### 4.10. Состояния
Оглушён, Сбит с ног (сдвиг на шкале), Ослеплён (дым), Обездвижен (проволока), Кровотечение, В иллюзии, Скрыт, На высоте.

### 4.11. Разные условия победы
- До нокаута.
- **Спарринг** до 30% HP или сдачи.
- **«Испытание колокольчиков»**: сорвать колокольчик с пояса за N ходов.
- **Забрать свиток** у противника.
- **Продержаться** N ходов.
- **Вытолкнуть** за край поля (турнир академии).

### 4.12. До боя: подготовка
- В открытом мире подкрался к врагу незамеченным — **засада** (первый ход и бонус).
- Перед сюжетными боями можно **расставить ловушки** на карте.
- **Подсумок** собирается заранее: что взял, тем и сражаешься.

### 4.13. Противники и их характер (ИИ)
| Противник | Стиль | Чему учит |
|---|---|---|
| Манекен | Обучение | Основы |
| **Киба + Акамару** | Быстрый натиск вплотную, «Клык» | Держать дистанцию |
| **Саске** | Скорость, контратаки, Каварими | Финты, выманивать реакции |
| **Наруто** | Толпа клонов, напор, импульсивность | Находить настоящего |
| **Шикамару** | Ловушки, анализ, лень (иногда пропускает ход) | Не лезть на подозрительные позиции |
| **Хината** | Оборона, Мягкий кулак (блок чакры) | Беречь чакру, бой без техник |
| **Чоджи** | Много HP, тяжёлые удары | Метание и манёвр |
| **Ино** | Иллюзии | Сопротивление гендзюцу |
| **Рок Ли** (секретный) | Чистое тайдзюцу, очень быстрый | Испытание мастерства |
| Хулиганы, вор, бродячие псы | Случайные события | — |
| **Мизуки** (финал) | 2 фазы, гигантский сюрикен, ложь и провокации | Всё сразу |

### 4.14. Аниме-подача
Линии скорости, стоп-кадр и замедление на критах, крупные планы при печатях, тексты-звуки (**БАМ!**, **ВЖУХ!**), облака дыма, полено при Каварими, тряска экрана, короткие реплики противников во время боя.

### 4.15. Поражение
- В спаррингах история идёт дальше (другой диалог, меньше оценка).
- В случайных боях: больница, травма (штраф к тренировкам на 1–2 дня), потеря части денег.
- Game over только в финале, повтор с чекпоинта.

## 5. Симуляция жизни ниндзя

### 5.1. Время
- **Календарь:** 8 недель (56 дней) до выпускного экзамена.
- **Время суток:** Утро (6–12), День (12–18), Вечер (18–22), Ночь (22–6).
- Время течёт само (на улице и в помещениях): **1 игровая минута ≈ 1,67 секунды**, игровые сутки = 40 реальных минут. Лечь спать (пропустить остаток дня) можно в любой момент у постели дома. В меню, диалогах, лавках и на карте часы стоят. Тренировки, работа и уроки пропускают время.
- **Расписание:** Пн–Пт утром уроки в академии (прогул снижает оценки и отношение Ируки), выходные свободны.
- **День заканчивается сном.** Лечь поздно — меньше энергии утром.

### 5.2. Нужды
| Нужда | Как работает |
|---|---|
| **Энергия** | Тратится на тренировки, работу и бег. Восстанавливается сном и онсеном. При нуле обморок и потеря времени |
| **Сытость** | Падает за день. Еда: дома (дёшево), Ичираку, Якинику, данго. Голод даёт штраф к тренировкам |

### 5.3. Деньги (рё) и подработки

#### Механики магазинов
- **Часы работы:** у каждой лавки своё расписание. Ночью почти всё закрыто, в выходные часть лавок не работает.
- **Ночной торговец:** в переулке в некоторые ночи появляется тайный продавец. Редкие товары, высокие цены, иногда подделки.
- **Скидки** до −20% за репутацию, дружбу с продавцом и навык «Обаяние».
- **Акции дня:** например, по вторникам в Ичираку рамен дешевле.
- **Продажа:** найденные травы, рыбу (рыбалка у озера и реки) и лишние вещи можно продать.
- **Ассортимент растёт по неделям сюжета:** новые товары появляются по мере учёбы.
- **Хранение:** **подсумок** ограничен слотами (это то, что берёшь в бой), а **сундук дома** хранит остальное.

### 5.6. Академия
- Уроки как короткие события: история Конохи (викторина), метание, спарринги, практика ниндзюцу, ловушки, выживание.
- Есть **оценки по предметам** и **отношение Ируки**. Всё это влияет на итог экзамена.
- **Турнир академии** в середине (неделя 4): серия дуэлей с одноклассниками.

### 5.7. Дружба и соперничество
- Уровни дружбы 0–5 (листки) с одноклассниками и жителями: Наруто, Саске, Сакура, Ино, Шикамару, Чоджи, Хината, Киба, Шино, Ирука, Теучи, Рок Ли и другие.
- Повышается разговорами, **подарками** (у каждого свои предпочтения), совместными тренировками и помощью.
- **На каждом уровне** открывается сцена и награда:
  - Наруто: Секси-дзюцу (шутка, ослепляет противников-мужчин 😄) или совместная проделка;
  - Шикамару: навык «Тактик» (+Анализ), шоги;
  - Рок Ли и Гай: новые тайдзюцу-комбо;
  - Хината: мазь для лечения (подарок);
  - Ирука: дополнительные уроки и «секретная» печать.
- **Соперничество с Саске** — отдельная шкала: побеждаешь его в спаррингах, и он начинает тебя уважать.

### 5.8. Репутация в деревне
Помощь жителям повышает репутацию: скидки, новые поручения, доверие стражей. Проделки репутацию снижают, но поднимают дружбу с Наруто.

### 5.9. Поручения и случайные события
- **Доска поручений** у резиденции Хокаге (неофициальные задания для учеников).
- **Случайные события:** потерявшийся ребёнок, хулиганы пристают к жителю, ночной вор, падающая с крыши черепица.
- **Секреты Конохи:** 20 спрятанных свитков по всей деревне. Все свитки дают секретную технику.

### 5.10. Дневник ниндзя (меню)
Журнал заданий (см. 2.6), цели на день и неделю, расписание уроков, дружба, техники, найденные свитки, статистика.

### 5.11. Стиль ниндзя и титулы
По тому, как ты играешь, складывается **стиль**: Мастер тайдзюцу, Ниндзюцу-специалист, Иллюзионист, Тактик, Универсал. Он даёт пассивный бонус и влияет на реплики персонажей и концовку.

## 11. Риски и решения

| Риск | Решение |
|---|---|
| Огромный объём контента | Генератор карты и шаблоны зданий. Сначала вертикальный срез, потом расширение |
| Файл слишком большой | Строковые спрайты, генерация вместо хранения, без base64 |
| Тормоза на большой карте | Чанки, отрисовка только видимого, NPC вне экрана обновляются упрощённо |
| Бой слишком сложен для телефона | Крупные кнопки ≥ 44 pt, обучение по шагам: механики открываются постепенно по неделям |
| Рутина симуляции | Мини-игры короткие (30–60 сек), убывающая отдача, события каждые пару дней |
| iOS «съедает» экран и звук | `100dvh`, режим «На экран „Домой“», звук по первому касанию |

## 14. Аудит плана: что застопорит разработку и чего не хватает

### 14.1. Узкие места: где работа может застрять

| # | Проблема | Почему это опасно | Решение |
|---|---|---|---|
| 1 | **Объём графики** | ~35 именных персонажей × 4 направления × 3 кадра, 20 портретов × 3 эмоции, бойцы 32×32 в разных позах. Вручную строками это сотни спрайтов | **Модульные спрайты («бумажная кукла»):** тело + причёска + одежда + цвета собираются кодом. Портреты тоже из частей: лицо, глаза, рот-эмоция, волосы. Героев аниме узнают по причёске и цветам, так что это работает. Уникально рисуются только ~12 ключевых |
| 2 | **Объём текста** | 56 дней, 60 сцен дружбы, ~55 заданий, реплики массовки. Ориентир 2500–4000 реплик | Компактный **скриптовый формат** диалогов и событий. Реплики массовки собираются из шаблонов. Писать по приоритету: сюжет → дружба → поручения → массовка |
| 3 | **Рутина 40 учебных дней** | Одинаковые уроки быстро надоедают | Расписание предметов по дням недели. 3 формата урока: мини-игра (30–60 сек), сюжетный урок, «отсидеть» (1 тап, результат по статам). Сюрпризы: контрольная, проделка Наруто, внезапный спарринг |
| 4 | **iOS стирает сохранения** ✅ | Safari удаляет `localStorage` сайта, если туда не заходили 7 дней. Хранилища Safari и иконки «Домой» **разные**, сохранение между ними не переносится | Играть **только через иконку «Домой»** (её не чистят). **Экспорт и импорт сохранения** текстовым кодом в настройках. Резервная копия во втором ключе |
| 5 | **Офлайн-режим и один файл** ✅ | Без Service Worker иконка «Домой» загружает страницу из сети при каждом запуске | **Решено:** рядом с HTML лежит маленький `sw.js`, игра работает полностью офлайн |
| 6 | **Беззвучный режим iPhone** | Web Audio молчит, когда включён переключатель «Бесшумно» | `navigator.audioSession.type = 'playback'` (iOS 17+), иначе подсказка игроку |
| 7 | **Потеря прогресса** | iOS выгружает вкладку в фоне. При автосейве только во сне можно потерять целый день | Автосейв при сворачивании (`visibilitychange` / `pagehide`) и раз в 2 игровых часа. Во время боя и катсцен не сохраняется |
| 8 | **Тупик с одним слотом** | Автосейв может застать героя без денег и еды, с травмой, перед обязательным боем | Страховка: дома всегда бесплатный рис, Академия выдаёт минимум 5 кунаев, больница бесплатна при 0 рё, проигранный сюжетный бой можно повторить, деньги не уходят в минус |
| 9 | **«Коноха как в аниме» из генератора** | Генератор строит однообразно, а править карту без инструмента тяжело | Отдельный **dev-редактор карты** (служебный HTML, в игру не входит): ставить здания мышью и экспортировать данные. Ориентиры ставятся вручную, декор генерируется. Честно: Коноха будет **сжатой**, узнаваемой по ориентирам, а не 1:1 по размеру |
| 10 | **Пиксельный шрифт с кириллицей** | Встроенного нет, а внешние шрифты в один файл не подтянуть | Свой bitmap-шрифт 6×8 (~4 КБ) для canvas. Длинные тексты (журнал, описания) — системным шрифтом в DOM |
| 11 | **Реакция за 1,5 сек** | Найти нужную печать в сетке из 12 за 1,5 сек пальцем почти невозможно | В момент реакции на экране 3–4 крупные кнопки. Каварими — одна большая кнопка-печать. Длительность окна настраивается |
| 12 | **Баланс 8-часовой игры** | Тестировщиков нет, перепроходить долго | Таблица баланса (формулы урона, кривые роста, экономика). В debug-режиме **авто-симулятор боёв** (1000 боёв за секунды) и чит-меню (неделя, статы, деньги) |

### 14.3. Чего не хватает

**Важное (влияет на всю игру):**
1. ✅ **Пол героя:** парень.
2. ✅ **Предыстория героя** (принята по умолчанию, можно поменять): родители-шиноби погибли при нападении Девятихвостого 12 лет назад, герой рос у родни на дальнем посту и вернулся в Коноху. Это параллель с Наруто и тема Воли Огня.
3. ✅ **Эпилог с командами:** герой становится четвёртым членом команды 7, 8 или 10 в зависимости от дружбы. Поэтому дружба с участниками этих команд — скрытый «выбор пути».
4. **Бои по желанию.** Сейчас глубокая боевая система используется ~10 раз за игру. Нужны **вызовы на спарринг** (одноклассники после уроков на полигонах, реванши), **рейтинг класса** и тренировочный бой с манекенами по уровням.
5. **Правила времени.** Время стоит в диалогах, меню, магазинах и бою, а в интерьерах идёт. Сюжетное событие нельзя пропустить: если игрок не пришёл, событие находит его само. За опоздание на урок оценка ниже.
6. **Ночь.** После 23:00 патрули чунинов отправляют учеников домой. Это лёгкий стелс (Хенге помогает) и ночные события.
7. **HP вне боя.** После спарринга HP восстанавливается полностью, после настоящих боёв нет. Лечение: еда, сон, больница.
8. **Постепенное открытие систем (онбординг).** День 1 — ходьба и диалоги, день 2 — еда и деньги, день 3 — тренировки, день 4 — дружба и подарки, неделя 2 — магазины и подработки полностью. Иначе 15 систем свалятся на игрока сразу.
9. **Формула экзамена.** Письменный тест (Знания и уроки истории) + метание + Буншин (мастерство) + характеристика Ируки (посещаемость и отношение). Пороги для 3 концовок.

**Нужное (без этого игра беднее):**

10. **Дом героя:** кровать (сон и сохранение), сундук, кухня (готовка), стол (учёба), календарь на стене, **цветок в горшке**, который надо поливать (мелочь, как у Наруто).
11. **Календарь событий на 56 дней:** фестиваль, дни рождения персонажей (подарок в этот день ценится ×2), акции, дождливые дни.
12. **Варианты ответов в диалогах.** Влияют на дружбу, репутацию и соперничество.
13. **Экран «Итоги дня»** перед сном: что выросло, деньги, дружба, что запланировано на завтра.
14. **Настройки:** скорость текста, отдельная громкость музыки и эффектов, подсказки и стрелка, мини-карта, **режим для левши** (геймпад зеркально), размер кнопок, длительность окна реакции.
15. **Пауза** при сворачивании и экран «Продолжить».
16. **Заглушка для альбомной ориентации** («Поверни телефон»): Safari не умеет фиксировать портрет.
17. **Версия сохранения и миграции.** Чтобы обновление игры не ломало старый сейв.

**Приятное (если хватит сил):**

18. Достижения («свитки достижений»).
19. Фото-режим со Скалы Хокаге.
