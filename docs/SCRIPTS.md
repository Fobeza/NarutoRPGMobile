# Язык диалогов и событий

Все разговоры, сюжетные сцены и реакции написаны на маленьком языке сценариев (разбор — `src/systems/script.js`).
Сценарии лежат строками внутри `G.script.parse(\`...\`)` в `src/data/dialogs.js`, `story_dialogs.js`, `story_scenes.js`
и в некоторых модулях `world/`.

## Пример

```
=== tenten_offer
tenten: Эй, {name}! Ты не видел мой кунай с красной лентой?
tenten(sad): Я потеряла его где-то у пристани...
?
* Помогу найти! -> yes
* [has.kunai] Возьми мой. -> give
* Некогда. -> no
# yes
call quest start lost_kunai
tenten(happy): Спасибо! Я буду на полигоне.
end
# give
call take kunai 1
call friend tenten 1
tenten: О! Он даже острее моего. Спасибо!
end
# no
tenten: Ну ладно...
end
```

## Строки

| Строка | Что делает |
|---|---|
| `=== id` | начало сценария с именем `id` (его указывают в `talk:` у NPC, в заданиях, событиях) |
| `naruto: текст` | реплика; `naruto` — id из `G.chars.DEFS` (портрет и имя подставятся сами) |
| `naruto(happy): текст` | реплика с эмоцией |
| `villager_m[Повар]: текст` | реплика со своим именем на табличке |
| `: текст` | повествование, без говорящего |
| `? вопрос` | текст перед выбором (можно пустой `?`) |
| `* вариант -> метка` | вариант ответа |
| `* [условие] вариант -> метка` | вариант виден только при условии |
| `# метка` | метка |
| `-> метка` | переход |
| `set flag.имя = 1` | флаг (0/1) |
| `set var.имя += 5` | число: `=`, `+=`, `-=` |
| `if условие -> метка` | условный переход |
| `call действие аргументы` | действие (таблица ниже) |
| `end` | конец сценария |
| `// …` | комментарий |

В тексте `{name}` — имя героя.

## Условия

| Условие | Истина, когда |
|---|---|
| `flag.x` / `!flag.x` | флаг установлен / не установлен |
| `var.x >= 3` | сравнение числа: `== != >= <= > <` |
| `quest.id` | задание активно; `quest.id.step` — активно и сейчас этот шаг |
| `qdone.id` | задание выполнено |
| `has.item` / `has.item.3` | в сумке есть предмет (не меньше 3) |
| `cooldown.x` | ещё действует пауза `call cooldown x …` |
| `weekday` / `rain` | будний день / идёт дождь |
| `skill.id` | у героя есть навык |

Полезные флаги и числа: `flag.met_<id>` (знаком), `flag.st_<id>` (сюжетное событие сыграно), `flag.tech_<id>` (знает технику),
`var.day`, `var.min` (минуты от полуночи), `var.money`, `var.friend_<id>`.

## Действия (`call`)

| Действие | Пример | Что делает |
|---|---|---|
| `quest start` | `call quest start lost_kunai` | начать задание |
| `step` | `call step lost_kunai find` | засчитать шаг |
| `qfail` | `call qfail lost_kunai` | провалить задание |
| `give` / `take` | `call give kunai 2` | дать / забрать предметы |
| `money` | `call money 50` | дать денег |
| `friend` | `call friend tenten 1` | +дружба |
| `met` | `call met tenten` | отметить знакомство |
| `battle` | `call battle tenten spar field win_id lose_id` | бой (режим, арена, сценарии после победы/поражения, `-` — нет) |
| `train` | `call train throw tenten` | тренировка-мини-игра (с другом) |
| `eat` / `rest` / `mood` | `call eat 25` | сытость / энергия / настроение |
| `time` / `wait` | `call wait 30` | перевести часы на время / подождать минут |
| `sleep` / `home` | `call sleep` | лечь спать / отправить домой |
| `cooldown` | `call cooldown rice 240` | пауза (минут) для условия `cooldown.rice` |
| `note` | `call note Найден свиток!` | всплывающее уведомление |
| `goal` | `call goal academy` | цель в верхней строке (`none` — убрать) |
| `courier` | `call courier` | выдать курьерское поручение |
| `sfx` | `call sfx puff` | звук |
| `charcreate` | `call charcreate` | экран вступительного теста |
| `askname` | `call askname` | ввод имени героя (после него идёт сценарий `hosp_after_name`) |
| `begin` | `call begin` | начало игры: включает автосохранение и сохраняет (конец пролога) |

Своё действие: `G.script.actions.имя = (args) => { ... }` в любом модуле (после `systems/script.js`).
Своё условие: обернуть `G.script.extraTest` (пример — `systems/life.js`).
