# Тесты и инструменты

Два слоя проверок:

1. **Без браузера (Node.js 18+)** — исполняют собранный `index.html` в заглушках DOM/Canvas: секунды, годятся после
   любой правки и для CI. См. «Проверки в Node» ниже.
2. **Браузерные (Playwright)** — открывают игру в эмуляции iPhone 15 Pro, нажимают кнопки, проверяют состояние
   и снимают скриншоты (в `tools/shots/`, в git не попадают). Установка: `pip install playwright` (браузер Chromium).
   Если Playwright не установлен, `check_all.py` помечает эти наборы как пропущенные, а не как упавшие.

## Одной командой

```bash
python3 tools/check_node.py          # только проверки в Node, ~12 с — после любой правки
python3 tools/check_all.py --quick   # сборка + Node + быстрые браузерные тесты, ~3 мин
python3 tools/check_all.py           # всё: Node + 6 наборов тестов + карта + комнаты, ~12 мин — перед публикацией
python3 tools/check_all.py --node    # сборка + Node-проверки, браузер и сервер не нужны
```

Сам поднимает сервер на порту 8765, в конце печатает сводку ✔/✘. Код выхода 0 — всё зелёное.

## Проверки в Node (`tools/node/`)

| Файл | Что делает |
|---|---|
| `harness.js` | Заглушки `document`/`canvas`/`localStorage`, загрузка `index.html` как модулей, запись вызовов рисования, сидируемый `Math.random`, готовое состояние героя |
| `checks.js` | 26 проверок: модули и предупреждения, целостность данных, 760 прогонов сценариев, генерация деревни на сидах, интерьеры, шрифт, 83 сцены `update`+`draw`, 20160 боёв и целевые окна баланса, сохранения |
| `balance.js` | Генератор `docs/BALANCE.md` и `docs/balance.csv` (запускается через `tools/balance.py N`) |
| `golden.js` | «Золотые отпечатки» для рефакторинга: хэш последовательности вызовов рисования в 56 боях и ~40 экранах |
| `targets.js` | Общий доступ к целевым окнам побед из `tools/targets.json` |

```bash
node tools/node/checks.js                      # то же, что python3 tools/check_node.py
N=200 SEEDS=7,13 node tools/node/checks.js     # больше боёв на ячейку, другие сиды деревни
node tools/node/golden.js > /tmp/before.txt    # до рефакторинга
# …правка… && python3 build.py
node tools/node/golden.js > /tmp/after.txt     # после; diff должен быть пустым
```

Проверки ловят то, что не видно глазами: битые ссылки в сценариях (`jump`/`call` на несуществующую метку, друга,
врага, предмет), недостижимые двери и объекты разговора, символы вне пиксельного шрифта, падения сцен при отрисовке,
выход баланса из целевых окон, поломку сохранений.

## Наборы тестов

| Файл | Что проверяет |
|---|---|
| `test_iphone.py` | Большой сквозной сценарий: создание героя, первый день, магазины, задания, карта, сон, нужды, патруль, дождь, статус, сохранение |
| `test_life.py` | Уроки, тренировки, дружба, доска поручений, события, экзамен, концовки |
| `test_battle.py` | Бой: меню, приёмы, техники, реакции, режимы, анимации |
| `test_recover.py` | Регрессии: события, прерванные выгрузкой вкладки; отработки уроков; сон до финала; ничьи в дружбе |
| `test_outdoor.py` | Травы, рыбалка, сундук, продажа, травничество, крыши |
| `test_calendar.py` | Календарь и перемещения персонажей по расписанию |

Тест считается упавшим, если в выводе есть `✘`. Помощники для своих тестов — `tools/tlib.py`
(`open_page`, `seed`, `W(page, js)` — выполнить код в сцене мира, `B(...)` — в бою, `key`, `shot`, `check`).

## Инструменты

### Ассеты V8
- `V8.md` — план, правила генерации и приёмки, реестр и журнал заходов.
- `tools/assets/manifest.json` — машинный реестр: промпты дословно, целевые размеры, статусы, вес.
- `python3 tools/assets/import.py` — импорт: декод PNG → кроп → масштаб в логическую сетку →
  квантование в `G.PAL` → `src/gfx/assets.js` (base64 внутри бандла). Без сторонних библиотек.
- `ASSETS_OFF=1 node tools/node/golden.js` — golden без ассетов (сравнение фолбэка);
  в браузере то же самое — `?assets=0`.

| Команда | Зачем |
|---|---|
| `python3 tools/render_map.py /tmp/map.png` | Вся карта Конохи в PNG + проверка недостижимых дверей и объектов (код выхода 1, если они есть) |
| `python3 tools/audit_rooms.py [--shots]` | Все комнаты: наложения мебели, недоступные NPC/предметы, вылезание за стены, «дыры» в полу; скриншоты в `tools/shots/rooms/` |
| `python3 tools/render_chars.py /tmp/c.png [id,id]` | Листы спрайтов и портреты персонажей |
| `python3 tools/balance.py [N]` | Симуляция боёв (N боёв на ячейку) → `docs/BALANCE.md` и `docs/balance.csv`; нужен Node, браузер не запускает |
| `python3 tools/check_node.py` | Все проверки без браузера (~12 с) |
| `python3 tools/render_houses.py`, `shot_spot.py` | Рендер домов, снимок конкретной точки карты |

## Отладка в браузере

`http://localhost:8765/?debug=1`: счётчик FPS и сцен, рамки коллизий, тап по карте — телепорт, «Читы» в меню.
В консоли браузера доступен весь `G` — например `G.state.vars.day = 20`, `G.game.give('kunai', 5)`.
