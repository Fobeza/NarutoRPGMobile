# Новый набор графики — 2.2.2

## Статус

В репозитории опубликованы **35 подготовленных мастер-изображений**, но они **ещё не подключены к игровому рендеру**. Мир продолжает использовать прежние рисунки: размеры объектов, коллизии, двери, свет и сохранения не менялись. Этот выпуск не объявляет замену всей графики завершённой.

Полный список файлов, размеры, SHA-256 и статус — `art/manifest.json`.

## Единый стиль

Ориентир — существующие дома (`art/houses/house01.webp`) и выбранный владельцем вариант дерева. Пиксельное аниме в духе Naruto: чёткий тёмный контур, цветовые кластеры, свет сверху слева, тёплые блики и холодные зелёно-синие тени. Дома и готовые персонажи не заменялись.

Стоящие объекты: вид сверху под углом; направление сверять с настоящими игровыми спрайтами, не разворачивать фасады произвольно в изометрию. Земля — строго сверху. Пропорции и точку опоры окончательно проверять на карте, а не по размеру ячейки в превью.

## Что входит

- 30 прозрачных WebP в `art/environment/`: дерево-эталон, куст, ящик, камень; бочка, скамейка, деревянный забор, два фонаря, колодец; доска, указатель, растение в кадке, папоротник, низкое дерево, компактный почтовый ящик, три разновидности камней; пять цветочных кустиков; дуб, берёза, сосна, ель, низкий клён и сакура.
- 5 отдельных PNG в `art/terrain/path/`: прямая север–юг, угол запад–север, выход вниз, начало внизу с выходом вверх, чистая трава. Каждый получен отдельной генерацией. Старый процедурно собранный набор удалён.
- Все новые оштукатуренные ограды (прямая, угол, боковая) удалены по просьбе владельца. Деревянный забор сохранён; существующая ограда в коде игры не затронута.
- Скамейка, деревянный забор и колодец перегенерированы с референсами из `G.environment.props`; старая большая версия почтового ящика заменена компактной.

## Размеры и публикация

- Окружение: не больше **512 px** по длинной стороне, цветы — не больше **256 px**.
- Земля: пять квадратных мастеров **512×512**. Это НЕ размер игрового тайла.
- Сохранены пропорции и прозрачность; уменьшение nearest-neighbor, WebP без потерь после уменьшения.
- Все 35 изображений занимают **6 706 998 байт (6,40 МиБ)**. Ни одно не превышает 512 КиБ. Бюджет набора — 8 МиБ.
- Размеры этих файлов **нельзя переносить напрямую на карту**. В игре тайл 16 логических точек, подробный холст HI=2. Игровую высоту дерева, ширину ящика, точку опоры и пятно коллизии назначать отдельно при импорте. Почтовый ящик должен быть небольшим предметом, не постройкой.
- Большие оригиналы сохранены локально в `assets/src/environment` и `assets/src/terrain` и исключены из Git существующим правилом `assets/src/`. В `main` идут все 35 выбранных изображений в компактном виде, не дубликаты PNG-исходников и не превью.

## Воспроизводимость

Нужен Python + Pillow (`python3 -m pip install pillow`).

```
python3 tools/package_art.py       # пересборка из локальных оригиналов assets/src
python3 tools/check_art_assets.py  # проверка опубликованных файлов; оригиналы не нужны
python3 build.py                  # обычная сборка игры не зависит от исходников арта
```

Проверяются список файлов, размеры, пропорции, альфа, хеши и бюджет. Публикация запрещает возвращать отменённую ограду. Сборщик арта требует все 35 оригиналов; в чистом checkout пользоваться готовыми файлами.

2. Для новых деревьев определить основание, перекрытие героя, тень и существующее пятно коллизии. Низкое дерево имеет почти скрытый ствол; плоский камень получился более округлым, чем планировалось.
3. Для фонарей подготовить маски свечения; для деревянного забора — проверить повтор секций.
4. У пяти изображений земли масштаб травинок, центры выходов и ширина отличаются. Они **не являются проверенным бесшовным тайлсетом**. Подогнать стыки перед подключением. Проверки удалённого процедурного набора к ним не относятся.
5. Перед подключением снимать кадры до/после и golden, прогонять build, check_node, полный check_all и браузерные JS-наборы. Пока новых механик, сюжета, баланса и формата сохранений нет.
