# Редактор карты на телефоне

Открыть: **https://fobeza.github.io/NarutoRPGMobile/map-editor.html**

Редактор начинается с пустой травяной карты 32×32. Это отдельный инструмент: игровая Коноха, сюжет и сохранения не меняются. Для новой карты можно выбрать 24, 32, 48 или 64 клетки по стороне.

## Управление

1. Выберите внизу категорию **Земля**, **Объекты** или **Дома**, затем нужный элемент. Рядом показан его рисунок.
2. **Кисть**: проведите пальцем, чтобы нарисовать покрытие; коснитесь, чтобы поставить предмет или дом. Используется текущая графика игры: 10 покрытий, 21 тип предметов, 100 рисунков зданий.
3. **Двигать**: перемещайте вид одним пальцем. Двумя пальцами можно перемещать и масштабировать в любом режиме. Есть кнопки **+**, **−**, **Вся карта**.
4. **Ластик** удаляет объект под пальцем; если объекта нет, возвращает траву. Для переноса объекта удалите его и поставьте заново.
5. **↶ / ↷** отменяют и возвращают целый мазок или действие (50 последних действий).
6. **Файл → Скачать JSON** — сохранить карту. **Открыть JSON** — продолжить работу. Импорт и создание новой карты требуют подтверждения и доступны для отмены.
7. **Картинка PNG** — полный вид карты без панели управления и сетки. PNG не заменяет редактируемый JSON.

Название меняется в меню «Файл». Объекты за границами холста не ставятся: для высоких деревьев и крыш нужно оставить место сверху. Проверка доступности дверей, маршрутов и сюжетных событий в этот редактор пока не входит; пересечения зданий допускаются как в графическом редакторе.

## Сохранность и офлайн

Черновик записывается в отдельный ключ `naruto-phone-map-v1` в localStorage. Игровые `wof_save_v1`, `wof_save_v1_bak`, `wof_settings` редактор не читает и не перезаписывает. Очистка данных браузера удалит черновик — **скачивайте JSON** для надёжного хранения и передачи.

`map-editor.html` — автономный файл около 3,43 МиБ: скрипты и графика внутри, внешние запросы не нужны. Его можно скачать через меню «Файл → Сам редактор HTML». На iPhone предпросмотр HTML в «Файлах» может не запускать JavaScript; рекомендуется опубликованная страница в Safari. На компьютере файл проверен с отключённой сетью. Реального устройства iPhone в тестовой среде нет.

## Формат карты

```json
{
  "format": "naruto-phone-map",
  "version": 1,
  "name": "Моя деревня",
  "w": 32,
  "h": 32,
  "ground": [0, 0],
  "objects": [{"kind":"prop", "id":"tree", "x":8, "y":8}]
}
```

В примере `ground` сокращён: настоящий массив должен иметь ровно `w*h` значений, построчно. Покрытия используют ID из `G.tiles.ID`. Размеры при импорте — целые от 16 до 64, не более 1500 объектов и 4 МиБ JSON. Разрешены только элементы текущей палитры.

Для предмета `x,y` задают клетку основания (точка привязки — центр по X, нижний край по Y). Для здания — левый верхний угол его участка; `id` — ключ `G.HOUSE_ART.art`. Рисунок дома позиционируется через штатные смещения спрайта.

**Это не готовое игровое сохранение и не формат старого dev-редактора `build/map_editor.html`.** Для превращения проекта в игровую локацию нужен отдельный импорт с размещением героя, дверей, коллизий, переходов и проверкой маршрутов. Пользователь может прислать JSON для такого подключения.

## Разработка

- Исходники: `src/editor/phone.html`, `src/editor/phone.js`.
- Сборка отдельно: `python3 tools/build_phone_editor.py`.
- Обычная `python3 build.py` также обновляет корневой `map-editor.html`.
- Генерируемый HTML вручную не редактировать.
- `node tools/test_phone_editor.js`: 320×568, 393×759, 430×932, реальные touch-жесты, подписи/кнопки, мазки, отмена/повтор, предметы/дома, JSON/PNG/HTML, офлайн, восстановление и изоляция игровых ключей.
