# Редактор карты — телефон и ПК

Актуально на 2026-10-21.

Открыть: **https://fobeza.github.io/NarutoRPGMobile/map-editor.html**

Редактор начинается с пустой травяной карты 32×32. Это отдельный инструмент: игровая Коноха, сюжет и сохранения не меняются. Для новой карты можно выбрать 24, 32, 48 или 64 клетки по стороне. Уже собранную карту можно изменить через «Файл → Размер текущей карты»: ширина и высота отдельно, от 16 до 96 клеток. При увеличении добавляется трава справа и снизу, прежние координаты остаются на месте. При уменьшении показывается предупреждение об обрезке и количестве удаляемых объектов. Отмена возвращает всю прежнюю карту.

## Управление

1. Выберите внизу категорию **Земля**, **Декор** или **Дома**, затем нужный элемент. Рядом показан его рисунок.
2. **Кисть**: проведите пальцем, чтобы нарисовать покрытие; коснитесь карты и перемещайте палец, чтобы выбрать место предмета или дома; размещение происходит при отпускании. Также можно перетащить миниатюру из нижней палитры прямо на карту. В палитре 10 покрытий, 57 типов предметов и 100 рисунков зданий. Для 36 новых предметов подключены отдельно сгенерированные изображения с видом сверху.
3. **Двигать**: перемещайте вид одним пальцем. Двумя пальцами можно перемещать и масштабировать в любом режиме. Есть кнопки **+**, **−**, **Вся карта**.
4. **Ластик** удаляет объект под пальцем; если объекта нет, возвращает траву. **Выбрать** позволяет схватить существующий объект и перетащить его. Отпускание за картой или отмена жеста оставляет исходный объект на месте.
5. **↶ / ↷** отменяют и возвращают целый мазок или действие (50 последних действий).
6. **Файл → Скачать JSON** — сохранить карту. **Открыть JSON** — продолжить работу. Импорт и создание новой карты требуют подтверждения и доступны для отмены.
7. **Картинка PNG** — полный вид карты без панели управления и сетки. PNG не заменяет редактируемый JSON.

### Мышь и клавиатура

На широком экране палитра расположена справа. Колесо приближает карту у курсора;
Пробел + ЛКМ или средняя кнопка перемещают вид. Горячие клавиши не перехватывают
ввод в полях/списках или открытом диалоге.

| Клавиши | Действие |
|---|---|
| V / B / E / H | Выбор / кисть / ластик / обзор |
| F / + / − | Вся карта / приблизить / отдалить |
| Стрелки, Shift + стрелки | Сдвиг выбранного объекта на 1 или 4 клетки |
| Delete / Backspace | Удалить выбранный объект |
| Esc | Отменить перенос, снять выделение |
| Ctrl/⌘ Z, Ctrl/⌘ Shift Z | Отмена и повтор |

Кнопка удаления есть в панели ПК; на телефоне используйте ластик.

### Размер, отражения и предпросмотр

- Выберите объект на карте кнопкой **Выбрать**. **↔ / ↕** отражают его по горизонтали/вертикали; список **50–200%** меняет масштаб с сохранением пропорций. Вертикальное отражение переворачивает весь рисунок, включая крышу/ствол — это не поворот в плане.
- Если объект на карте не выделен, эти настройки применяются к следующему размещаемому объекту. **×** снимает выделение.
- Во время перетаскивания рисунок полупрозрачный. Зелёная сетка и подпись показывают, сколько клеток занимает его прямоугольная область; красная сетка предупреждает о выходе за карту. Для зданий дополнительно показывается размер участка из шаблона.
- Это визуальные габариты, **не рассчитанная игровая коллизия**. У прозрачного спрайта в прямоугольнике могут быть пустые клетки. Отражение не меняет прямоугольные габариты, масштаб меняет их.
- Перенос, масштабирование, отражения и изменение размера карты отменяются/повторяются. Если увеличенный объект не помещается, операция отклоняется: сначала переместите его дальше от края.

Название меняется в меню «Файл». Объекты за границами холста не ставятся: для высоких деревьев и крыш нужно оставить место сверху. Проверка доступности дверей, маршрутов и сюжетных событий в этот редактор пока не входит; пересечения зданий допускаются как в графическом редакторе.

## Сохранность и офлайн

Черновик записывается в отдельный ключ `naruto-phone-map-v1` в localStorage. Игровые `wof_save_v1`, `wof_save_v1_bak`, `wof_settings` редактор не читает и не перезаписывает. Очистка данных браузера удалит черновик — **скачивайте JSON** для надёжного хранения и передачи.

`map-editor.html` — автономный файл около 3,80 МБ (3,62 МиБ): скрипты и графика внутри, внешние запросы не нужны. Его можно скачать через меню «Файл → Сам редактор HTML». На iPhone предпросмотр HTML в «Файлах» может не запускать JavaScript; рекомендуется опубликованная страница в Safari. На компьютере файл проверен с отключённой сетью. Реального устройства iPhone в тестовой среде нет.

## Формат карты

```json
{
  "format": "naruto-phone-map",
  "version": 2,
  "name": "Моя деревня",
  "w": 32,
  "h": 32,
  "ground": [0, 0],
  "objects": [{"kind":"prop", "id":"tree", "x":8, "y":8, "scale":1, "flipX":false, "flipY":false}]
}
```

В примере `ground` сокращён: настоящий массив должен иметь ровно `w*h` значений, построчно. Покрытия используют ID из `G.tiles.ID`. Размеры при импорте — целые от 16 до 96, не более 1500 объектов и 4 МиБ JSON. Разрешены только элементы текущей палитры.

Для предмета `x,y` задают клетку основания (точка привязки — центр по X, нижний край по Y). Для здания — левый верхний угол его участка; `id` — ключ `G.HOUSE_ART.art`. Рисунок дома позиционируется через штатные смещения спрайта.

Старые проекты версии 1 загружаются автоматически: масштаб по умолчанию 100%, отражения выключены. Экспорт теперь версии 2; старый редактор версии 1 такие файлы не откроет. Ключ черновика сохранён для миграции существующих проектов.

**Это не готовое игровое сохранение и не формат старого dev-редактора `build/map_editor.html`.** Для превращения проекта в игровую локацию нужен отдельный импорт с размещением героя, дверей, коллизий, переходов и проверкой маршрутов. Пользователь может прислать JSON для такого подключения.

## Разработка

- Исходники: `src/editor/phone.html`, `src/editor/phone.js`.
- Сборка отдельно: `python3 tools/build_phone_editor.py`.
- Обычная `python3 build.py` также обновляет корневой `map-editor.html`.
- Генерируемый HTML вручную не редактировать.
- `node tools/test_phone_editor.js`: 320×568, 393×759, 430×932, реальные touch-жесты, подписи/кнопки, мазки, отмена/повтор, предметы/дома, JSON/PNG/HTML, офлайн, восстановление и изоляция игровых ключей.

Расширенные регрессии: `tools/test_editor_transform.js` проверяет v1→v2, реальные перемещения пальцем из палитры и на карте, сетку предпросмотра, отмену жеста, отражённые пиксели PNG, масштаб, увеличение/обрезку, отказ от обрезки, отмену/повтор и восстановление JSON на трёх телефонах.


## Новый арт объектов

Все 36 добавленных предметов теперь используют новые изображения, а не прежнюю
процедурную графику. Старые ID, координаты и рамки сохранены: проекты v1/v2
открываются без миграции. Для мелких растений используйте масштаб объекта
или приближение карты. В PNG попадает тот же арт, включая отражения.

Стены: прямые секции ставятся с шагом 2 клетки. У ворот заходите стеной на
1 клетку под край крыши, чтобы соединить её с опорой (ворота x=12 → стены x=11
и x=19 на том же y). Для углов допускается наложение. Это отдельные рисунки,
не автоматическое соединение: фактура стыков может быть заметна.
