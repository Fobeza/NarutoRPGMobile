# Пять отдельных генераций земли

1. `01-straight.png` — трава слева/справа, тропинка открыта сверху и снизу.
2. `02-corner-left-up.png` — поворот между левым и верхним краями.
3. `03-down.png` — верхнее закругление среди травы, выход вниз.
4. `04-up.png` — нижнее начало, выход вверх.
5. `05-grass.png` — трава без тропинки.

Каждый файл — отдельная генерация, не программно нарисованная форма. Для публикации 2.2.2 исходники 1254×1254 уменьшены до 512×512 без изменения пропорций; большие оригиналы хранятся локально в `assets/src/terrain` и не входят в Git. Старый набор, собранный из двух текстур, удалён.

Эти мастер-файлы не следует стыковать напрямую. Для игры `tools/import_environment.py` готовит уменьшенные материалы с согласованными краями; `src/gfx/terrain_art.js` выбирает поворот/окончание по соседним клеткам. Широкие дороги сохраняют сплошной грунт, а игровая клетка остаётся 16×16 логических точек. Исходные PNG не менялись. Подробнее: `docs/ART_STYLE.md`.
