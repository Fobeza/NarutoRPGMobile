# Каменное мощение

`street.webp` — мастер 512×512, строгий вид сверху, тёплый серо-бежевый камень.
Импорт: `python tools/import_environment.py` (Pillow), затем `python build.py`.
В игру встраивается материал 128×128 с согласованными краями; мастер напрямую не загружается.
Переходы к существующим траве/грунту вычисляет `src/gfx/street_art.js` по мировым координатам.
Исходник генерации: игнорируемый `assets/src/terrain/stone/street-source.png`.
