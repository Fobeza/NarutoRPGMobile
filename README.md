# Naruto RPG — «Воля Огня»

Фанатская пиксельная RPG по «Наруто» для браузера (рассчитана на iPhone, портретная ориентация).
Текущая версия — **2.5**: бой стал тактической карточной дуэлью с точными намерениями врагов, связками карт и 21 проверенной победной стратегией. Сохранены фиолетовая чакра, развитие героя и мобильное управление. Графика встроена в HTML и работает офлайн; в игру также входят обновлённые деревня, меню, статус, сумка, уличные события и диалоги.

Перестройка игры продолжается: старая кампания «Первое обещание» и «Дороги Листа» удалены. Новый сюжет — герой без памяти
и необычной фиолетовой чакрой, три недели до экзамена на генина; время по месяцам, всегда лето; усталость вместо голода; новый бой.
Пока работают деревня, жители, Академия с уроками, тренировки, дружба, магазины и текущий бой. План работ — `docs/TODO.md`.

**Играть:** https://fobeza.github.io/NarutoRPGMobile/ (в Safari: «Поделиться → На экран Домой» — будет как приложение и работает без интернета).

## Сборка и проверка

```bash
# 1. поправить файлы в src/  (что где лежит — ниже и в docs/)
python3 build.py                    # 2. собрать → index.html + sw.js + map-editor.html
python3 tools/check_node.py         # 3. быстрые проверки без браузера (~12 с, нужен Node.js 18+)
python3 tools/check_all.py --quick  # 4. то же + браузерные тесты (полная проверка — без --quick)
# После проверок: коммит в рабочую ветку → PR → merge в main → дождаться GitHub Pages
```

Никаких зависимостей для сборки и для самой игры: только Python 3. Node.js нужен для быстрых проверок
(`tools/node/`), Playwright — для браузерных тестов и скриншотов (`pip install playwright`).
Полный прогон включает также отдельные JS-наборы: [TESTING.md](docs/TESTING.md).

Посмотреть игру локально: `python3 -m http.server 8765` в корне → http://localhost:8765/ (с `?debug=1` — режим отладки).

│   ├── systems/           ЛОГИКА: время, задания, Академия и уроки, сюжет, дружба, тренировки, катсцены, расписания…

│   ├── gfx/               графика: палитра, шрифт, набор интерфейса (ui.js), тайлы, отрисовка персонажей

## Управление

Крестовина — ходьба, **A** — говорить/действовать, **B** — назад/отмена, **МЕНЮ** — задания, календарь, статус, сумка, сохранение,
**КАРТА** — большая карта, **ЦЕЛЬ** — подсказка пути к текущему заданию.

## Редактор карты на телефоне и ПК

[Открыть редактор](https://fobeza.github.io/NarutoRPGMobile/map-editor.html) · [Инструкция](docs/MAP_EDITOR.md)

Пустая карта, игровые покрытия, дома и предметы; рисование пальцем, перенос объектов из палитры и по карте с предпросмотром клеток, размер/отражения объектов, изменение размеров карты до 96×96, перемещение/масштаб вида двумя пальцами, отмена, JSON и PNG. Автономный файл `map-editor.html` собирается вместе с игрой. Редактор не меняет Коноху и игровые сохранения; подключение созданной карты к игре — отдельный этап.

Палитра: 10 покрытий, 57 предметов, 100 домов. Все 36 новых мастеров подключены.
На ПК — мышь, колесо, боковая панель и горячие клавиши; см. инструкцию.
