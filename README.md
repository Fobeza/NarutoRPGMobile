# Naruto RPG — «Воля Огня»

Фанатская пиксельная RPG по «Наруто» для браузера (рассчитана на iPhone, портретная ориентация).
Герой возвращается в Коноху и 8 недель учится в Академии: уроки, тренировки, дружба, подработки,
сюжет из аниме, турнир и выпускной экзамен.

**Играть:** https://fobeza.github.io/NarutoRPGMobile/ (в Safari: «Поделиться → На экран Домой» — будет как приложение и работает без интернета).

---

## Как обновить игру (коротко)

```bash
# 1. поправить файлы в src/  (что где лежит — ниже и в docs/)
python3 build.py                    # 2. собрать → index.html + sw.js в корне
python3 tools/check_node.py         # 3. быстрые проверки без браузера (~12 с, нужен Node.js 18+)
python3 tools/check_all.py --quick  # 4. то же + браузерные тесты (полная проверка — без --quick)
git add -A && git commit -m "что изменил" && git push   # 5. через 1–2 минуты сайт обновится сам
```

Никаких зависимостей для сборки и для самой игры: только Python 3. Node.js нужен для быстрых проверок
(`tools/node/`), Playwright — для браузерных тестов и скриншотов (`pip install playwright`).
Посмотреть игру локально: `python3 -m http.server 8765` в корне → http://localhost:8765/ (с `?debug=1` — режим отладки).

## Где что лежит

```
NarutoRPGMobile/
├── index.html, sw.js      ← СОБРАННАЯ ИГРА (не править руками — перезаписывается build.py)
├── build.py               сборщик: склеивает src/ в один index.html (порядок модулей — список JS_FILES)
├── src/
│   ├── data/              ДАННЫЕ — сюда заходишь чаще всего
│   │   ├── characters.js    внешность всех персонажей (цвета, причёски, одежда, детали)
│   │   ├── schedule.js      расписание персонажей (где кто бывает по часам и дням)
│   │   ├── dialogs.js       диалоги персонажей (язык сценариев — docs/SCRIPTS.md)
│   │   ├── story_dialogs.js, story_scenes.js   сюжетные сцены и катсцены
│   │   ├── quests.js        задания
│   │   ├── items.js         предметы и магазины
│   │   ├── combat.js        враги, их приёмы, техники, комбо, арены
│   │   ├── hero.js          характеристики и навыки героя
│   │   ├── buildings.js     шаблоны зданий
│   │   └── konoha_layout.js раскладка деревни (правится редактором карты)
│   ├── systems/           ЛОГИКА: время, задания, Академия и уроки, сюжет, дружба, тренировки, катсцены, расписания…
│   ├── world/             МИР: генератор Конохи, интерьеры комнат, жители и их реплики, крыши, эффекты
│   ├── scenes/            ЭКРАНЫ: карта мира, бой, мини-игры, меню, сумка, календарь, магазин…
│   ├── gfx/               графика: палитра, шрифт, тайлы, отрисовка персонажей
│   ├── engine/            движок: экран, управление, звук, сцены, сохранения
│   └── main.js, shell.html, style.css, sw.js
├── tools/                 автотесты и утилиты (рендер карты, персонажей, баланс, аудит комнат)
└── docs/                  документация
```

## Управление

Крестовина — ходьба, **A** — говорить/действовать, **B** — назад/отмена, **МЕНЮ** — задания, календарь, статус, сумка, сохранение,
**КАРТА** — большая карта, **ЦЕЛЬ** — подсказка пути к текущему заданию.
